## Full announcement

**FastS3 v1.0.0 is released — a single-node high-performance S3 service for raw block devices / disk images**

- **Performance**: io_uring + thread-per-core + O_DIRECT, targeting 90%+ of the fio raw-disk baseline
  at the protocol layer (§6.8 target table; numeric reports ship with the version);
- **Compatibility**: aws cli / boto3 / mc / rclone zero-config; s3-tests supported subset
  100% (full regression + exclusion-set methodology);
- **Reliability**: 1000 crash rounds + power-loss simulation with zero tear and zero leak; data flushed first, metadata committed after;
  disk-full / disk-loss / clock-jump degrade by design;
- **Out of the box**: one-command install → `fasts3d init` wizard, service up in 5 minutes; systemd and
  container dual form; one-command upgrade, auto-rollback on failure, N-1 in-place upgrade guarantee;
- **Operations**: full console ops loop (dashboard / buckets / object direct transfer / keys / policies / audit / settings);
  Prometheus + Grafana assets one-click import; doctor one-shot health check; metadata snapshot + volume snapshot
  dual-insurance backup; mc/rclone migration scripted;
- **Security**: least exposure by default (admin loopback + random token + TLS bootstrap + secret hashing);
  artifact signature + SBOM; dual dependency-audit zero-vuln gates; external security audit before GA;
- **Download and verify**: tarball / deb / rpm (amd64, arm64) + minisign signature +
  CycloneDX SBOM; `install.sh` one-command install; verify script `verify-release.sh`.

## Upgrade guidance (users)

```bash
# One-command install/upgrade (replace the old binary):
curl -fsSL <download-root> | sh
# or N-1 in-place upgrade:
fasts3d upgrade            # layout auto-migrates; auto-rollback on failure
# Verify artifact signatures and SBOM:
bash tools/package/verify-release.sh <artifact-dir>
```
