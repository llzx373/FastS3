# FastS3 v1.0.0 GA 发布公告

> 发布日期:2026-08-21(候选);正式公告随 GA 检查单复核 + RC 流程全部门禁
> 通过后启用(细节见 `docs/ga/rc-flow.md`)。本文为公告终稿与发布渠道清单。

## 公告全文

**FastS3 v1.0.0 正式发布 — 面向裸块设备/磁盘镜像的单机高性能 S3 服务**

- **性能**:io_uring + thread-per-core + O_DIRECT,目标达到 fio 裸盘基线
  的 90%+ 协议层吞吐(§6.8 目标表;数值报告随版本发布);
- **兼容**:aws cli / boto3 / mc / rclone 零配置对接,s3-tests 支持子集
  100%(全量回归 + 排除集方法论);
- **可靠**:崩溃 1000 轮 + 断电模拟零撕裂零泄漏;数据先落盘、元数据后提交;
  磁盘满/掉盘/时钟回拨按设计降级;
- **开箱**:一条命令安装 → `fasts3d init` 向导 5 分钟起服务;systemd 与
  容器双形态;升级一条命令、失败自动回滚、N-1 原地升级保证;
- **运维**:控制台完整运维闭环(仪表盘/桶/对象直传/密钥/策略/审计/设置);
  Prometheus + Grafana 资产一键导入;doctor 一键体检;元数据快照 + 卷快照
  双保险备份;mc/rclone 迁移脚本化;
- **安全**:默认最小暴露(admin 回环 + 随机 token + TLS 引导 + secret 哈希);
  产物签名 + SBOM;依赖双 audit 清零门禁;GA 前外部安全审计;
- **下载与验证**:tarball / deb / rpm(amd64、arm64)+ minisign 签名 +
  CycloneDX SBOM,`install.sh` 一条命令安装;校验脚本 `verify-release.sh`。

## 更新指引(用户)

```bash
# 一条命令安装/升级(替换旧二进制):
curl -fsSL <下载根> | sh
# 或 N-1 原地升级:
fasts3d upgrade            # 布局自动迁移,失败自动回滚
# 校验产物签名与 SBOM:
bash tools/package/verify-release.sh <产物目录>
```

详见 [5 分钟开箱](../getting-started/quickstart.md) 与
[升级与回滚](../operations/upgrade.md)。
