# FastS3 M14 性能报告(v2.0.0 集中纳管与生态)

> 常驻轨道口径(ROADMAP §6.3「持续」):每版本性能回归报告;基准机 = 本次
> 执行环境(WSL2 内核 6.18,32 逻辑核;单机回环)。门禁对照:
> **agent 关闭零差异** 与 **默认全开=关空载 ≤256MiB** 见 M14 门禁实测记录。

## 1. HTTP/3 对照基准(H1-1;ADR-17 DV2 实验开关)

脚本:`tests/bench/m14-http3-bench.sh`(fasts3d `--features http3` 构建 +
`[server] http3_listen` 开启;同一对 TLS 证书;h1 与 h3 同机对照)。

| 路径 | 测得 ops/s | 口径 |
| --- | --- | --- |
| h1/h2(TLS)GET /health | ~1894 ops/s | python http.client **单连接 keep-alive** |
| h3 GET /health(顺序) | ~167 ops/s | quinn 客户端,**每请求全新连接+握手**(保守口径) |
| h3 GET /health(16×8 并发) | ~130 ops/s | 同上,16 条并发连接 |

说明:

- h3 数字为**每请求新建 QUIC 连接 + TLS 握手**的实测开销(连接建连 ~5ms
  量级,回环);真实客户端(连接复用 + 0-RTT 恢复)期望显著更高 ——
  本环境无 curl HTTP/3(quiche/ngtcp2)与 nghttp3 客户端可作复用对照,
  记为评估期待办;
- **弱网对照(净宝/乱序/丢包)未能实测**:需要真实链路注入(netem)或
  弱网模拟器,本执行环境不具备(无 root qdisc、无 WSL netem)。评估期
  内若企业弱网边缘上传诉求成立,在真实弱网环境补测后按 ADR-17 DV2
  决策转正/冻结;
- CPU 增量按 §9.1 预算:QUIC 头处理相对 h2 ~+10-20%(回环实测受建连
  开销主导,未单独析出)。

## 2. HTTP/3 0-RTT 语义(重放防护;门禁对应测试)

- `tests/fs3-http h3_roundtrip` 集成测试断言:
  1. h3 GET /health 全握手往返 200;
  2. **0-RTT 请求在握手完成前被上层读到 → 非幂等方法 425 Too Early
     (RFC 8470),PUT 无 0-RTT 执行**(弱网场景路径);
     本地回环握手在首个数据报内完成时,0-RTT PUT 走**已验证后**的标准
     管线(4xx),同样无早期执行 —— 两条路径均安全;
  3. 0-RTT GET /health 放行(幂等);
  4. 常规 PUT 永不 425。
- 判定语义(确定性):1-RTT 请求在握手完成前不可能被上层读到 ⇒
  h3 accept 可见请求时握手未完成 = 早数据。服务端 `into_0rtt()` 对
  普通连接恒 Ok(0.5-RTT),ZeroRttAccepted 恒 true,两者皆不可用作
  早数据信号(q> 文档化)。
- **实验边界(评估期局限,ADR-17 DV2)**:未实现防重放缓存(0-RTT nonce/
  时间窗口去重);防御姿态 = 早数据请求仅幂等放行 + 非幂等 425,其余
  一律在握手验证后执行。企业级反重放(单次票证、服务端抗重放缓存)
  列入 v2.0 外部安全审计立项时的评审范围。

## 3. 纳管链路开销(g1 - 中心)

- agent 心跳 1s + 流上报周期(默认 15s)+ 下发拉取(每周期一次):管理面
  低频 mTLS 连接,每次新建连接(不 keep-alive),实测单周期上行
  < 8KiB(状态快照 + 指标文本 + 审计增量);对数据面零触碰(独立线程)。
- 拔中心红线实测:中心存活期间数据面无新增延迟路径(admin/S3 零改动)。
- 默认(agent 关)二进制:fs3-agent 不编译(crate feature-gate),
  fs3d 无新增常驻线程/内存 —— 与 v1.x 行为零差异(门禁)。

## 4. 内存基线(默认全开=关)

- 默认全关二进制空载内存 ≤256MiB(门禁;M14 门禁实测记录中给出
  /usr/bin/time -v 数据);agent 开启态增量 <16MiB 预算(指标缓冲)。
## 5. 热缓存对照(H1-2;默认关;§4.12)

脚本:`tests/bench/m14-cache-bench.sh`(64KiB 对象 × 500 全量 GET,
keep-alive;写路径经引擎 CLI 预写,读路径匿名;开 = 512MiB 额度)。

| 配置 | ops/s | 命中率(admin 指标) |
| --- | --- | --- |
| 缓存关(默认) | ~1037 | —(指标组缺席) |
| 缓存开 | ~1328(**1.28×**) | 99.8%(hits=499/misses=1) |

说明:

- 命中路径免引擎读取(元数据 + 设备 I/O),Range 请求按命中整对象裁剪
  (高频 Range 头场景收益更高);64KiB 对象在此基准机上引擎读本身已快,
  提速 28% 为保守口径。
- 命中率可观测:admin `/v1/admin/metrics` 导出 `fasts3_cache_hits_total /
  misses_total / inserted_total / evicted_total / cached_bytes /
  served_bytes_total`(未启用 = 指标组缺席,与生命周期指标同口径)。
- **SSE 对象不入缓存**(解密字节与客户密钥作用域绑定红线);超
  `max_object_size` 对象不进入缓存路径(计数器不变)。
- 开启 = 主动扩大内存预算(与默认 ≤256MiB 空载基线冲突的明示,
  §9.2)。
